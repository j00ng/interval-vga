# School visibility example

This directory is an application example, not part of the engine's domain model.

The existing corridor/courtyard experiments use seated and standing human profiles,
classroom windows, and school-specific reporting metrics. They demonstrate how a
project can configure the general `interval_vga` API; the engine itself contains no
teacher, student, classroom, corridor, or school concepts.

The original research scripts remain at the repository root until their historical
outputs and command-line interfaces have been migrated and regression-tested.
